`main` 브랜치에 push될 때마다 GitHub Actions가 자동으로 빌드해서 위 주소에 배포합니다.

## GitHub에서 직접 해야 하는 설정 (최초 1회)
1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
2. 작업 브랜치를 `main` 에 머지합니다. 배포는 `main` 에 push될 때만 실행됩니다.
3. **Actions** 탭에서 `Deploy to GitHub Pages` 워크플로가 초록색으로 끝났는지 확인하고 위 주소에 접속합니다.
   - 첫 배포 전에 1번을 하지 않았다면 실패하므로, 설정 후 Actions 탭에서 **Re-run jobs** 를 누릅니다.
   - 워크플로 화면의 **Run workflow** 버튼으로 수동 배포도 할 수 있습니다.
4. 저장소가 **비공개(private)** 라면 무료 플랜에서는 Pages를 쓸 수 없습니다. 공개로 바꾸거나 유료 플랜이 필요합니다.

## 모바일
휴대폰·태블릿에서 열면 화면 버튼이 자동으로 나옵니다. **가로 화면**으로 플레이합니다. (PC 에서 버튼을 보려면 주소 끝에 `?touch=1`)

| 버튼 | 동작 (키보드) |
|---|---|
| 왼쪽 방향 패드 | 손가락 위치로 8방향 이동·조준 (←→↑↓) |
| 점프 | Space |
| 공격 | X (탭 = 휘두르기, 회전 차지가 있으면 꾹 누르기 = 차지) |
| 당기기 | C (탭 = 당기기, 철퇴 폭풍이 있으면 꾹 누르기 = 회전) |
| 대시 | Shift |
| 스킬 | K — 스킬 트리. 칸을 탭해서 배우기/해제, 열려 있을 때 '무기 바꾸기'(Q)·'태그 페이지'(T) 버튼이 나옴 |
| 처음부터 | R |
| 전체화면 | 전체화면 + 가로 고정 (지원하는 브라우저만. iOS Safari 는 홈 화면에 추가하면 주소창이 사라짐) |

여러 손가락을 동시에 쓸 수 있습니다 (예: 방향 패드를 누른 채로 점프·대시).

## 게임 설명 (프로토타입)
방을 클리어할 때마다 스킬을 쌓아 가는 로그라이트의 프로토타입입니다. 주 무기는 **사슬**이고, 테스트용 적과 시험 맵에서 스킬을 하나씩 확인합니다. 수치는 모두 초안입니다.

### 조작
| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| Space | 점프 (공중에서 한 번 더 누르면 2단 점프, 짧게 누르면 낮게 점프) |
| X | 사슬 휘두르기. 박자 맞춰 연타하면 3단 콤보 (채찍 → 되감아 치기 → 내려치기). 사슬 **끝부분(분동)** 으로 맞히면 추가 피해. **회전 차지** 스킬이 있으면 탭 = 휘두르기, 꾹 누르기 = 차지(투사체 쳐냄), 놓으면 방출 |
| C | 특수: 사슬 당기기 (↑↓ 로 위아래 조준). **철퇴 폭풍**이 있으면 꾹 누르기 = 회전, 놓을 때 방향 입력(앞·↑·↓)으로 붙잡은 적을 한꺼번에 날림 |
| Shift | 대시. 공중에서도 1번 가능, 대시 중에는 무적 |
| K | 스킬 트리 (게임 일시정지). 스킬을 클릭하거나 ↑↓ + Enter 로 배우기/해제, **Q** 주 무기 바꾸기(사슬 ↔ 검), **T** 무기·이동 트리 ↔ 공용 증강(태그) 페이지 |
| P | 테스트용: 가장 가까운 적이 플레이어를 향해 투사체를 쏨 (쳐내기 시험) |
| R | 처음부터 다시 (스킬·방 초기화) |

주소 끝에 붙이는 옵션: `?touch=1` 화면 버튼, `?level=level1` 옛 시험 맵, `?difficulty=0~3` 난이도(성흔 단계, 돌격형의 돌진 준비시간이 줄어듦).

### 스킬
지금은 테스트용으로 **K 스킬 트리 화면에서 직접** 스킬을 배우거나 해제합니다. (방을 클리어하면 후보 중 하나를 고르는 창은 `src/data/skills.json` 의 `pickOnRoomClear` 를 `true` 로 바꾸면 다시 켜집니다.) 자세한 동작과 수치는 [CLAUDE.md](CLAUDE.md) 의 '현재 상태'와 `src/data/` 를 보세요.

**사슬 (무기) 트리** — 결박·투척·분동 세 갈래, 갈래마다 3단계 (모두 구현)
| 갈래 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 결박 | **감기**: 끝부분 적중 시 1초 속박(끝난 뒤 1.5초는 재속박 불가), 사슬은 3초 유지(동시 3명) | **팽팽한 줄**: 묶인 적 사이 사슬 선에 닿은 적은 피해·속박, 묶인 적이 2명 이상이면 C 로 서로 충돌시킴 | **사슬 감옥**: 묶인 적이 죽으면 주변에 전이, C 로 한 점에 모아 폭발 |
| 투척 | **회전 투척**: 당긴 적을 던짐(↑ 면 띄움) | **내리찍기**: 공중 상태 적을 감아 바닥에 꽂고 충격파 | **철퇴 폭풍**: C 꾹 → 사슬을 돌려 여러 적을 붙잡고, 놓으면 앞(벽·맵 끝에서 폭발) / ↑(띄우기) / ↓(바로 내리찍기) |
| 분동 | **회전 차지**: X 꾹 → 차지·쳐내기, 방출 때 사슬 길이 자동 보정, 방출 사슬 길이 +40%(최대 약 10칸, 기본 공격은 그대로) | **쳐내기 축적**: 쳐낸 투사체를 최대 5개 저장, 방출 시 전방 75° 부채꼴 반사 | **채찍 폭풍**: 회전 스택, 최대 스택 방출은 전방으로 넓은 아치 범위 |

**대시 (이동) 트리**
1. **대각선 대시** — Shift 를 ↑↓(+←→) 와 함께 누르면 위·아래·대각선으로 대시
2. **사슬** — 대시 대신 사슬을 던짐. 지형·적에 걸리면 잠깐 멈칫한 뒤 바로 그곳으로 날아가고, 적이면 붙으며 피해
3. **내리꽂기** — 사슬로 이동한 직후(머리 위 ▼ 표시) 공격하면 분동을 크게 휘둘러 앞쪽 땅에 내리꽂음

**공용 증강 태그 (테스트용 트리, K → T)** — 번개·불·얼음·구속·처형 5종. 태그 개수 1/3/5개에서 효과가 단계별로 강해지고, 사슬의 연결 지점(끝부분 적중 등)에서 확률로 발동합니다. 태그 증강 본체는 아직 없어서 트리 화면에서 노드를 배워 개수를 올립니다.

### 적과 맵
- **더미**: 좌우로 순찰하는 테스트용 적 (체력 150)
- **돌격형**(주황색): 다가오다가 준비(머리 위 느낌표) → 돌진 → 약 5초 근접 공격(개체마다 ±20%) → 바로 다시 돌진. 돌진은 평타로 끊을 수 없고 속박·스턴·빙결 같은 제어 스킬만 끊음(플레이어를 맞히면 돌진이 끝남)
- **원거리형**(파란색): 거리를 유지하다가 준비 중 공격 궤도를 **빨간 선**으로 보여 준 뒤(마지막 0.3초는 고정) 탄속이 빠른 탄을 발사. 맞으면 피격, 회전 차지로 쳐낼 수 있음
- 기본 맵 `bind.txt` (102×17 타일): 맨 왼쪽 구역 D = 돌격형 4마리 + 원거리형 3마리, 그 오른쪽부터 시작 구역 A(촘촘한 4마리), B(넓게 벌어진 3마리), C(5마리 + 발판). 구역 사이는 2칸 기둥입니다. 구역별로 시험할 스킬은 `docs/TESTING.md` 에 있습니다.

### 구조
- `src/data/` — 모든 수치와 데이터. 튜닝은 여기서: `player.json`(플레이어·무기·사슬), `enemies.json`(적, 돌격형 AI 수치), `skills.json`(스킬 트리), `tags.json`(태그 공명), `difficulty.json`(난이도 단계), `game.json`, `levels/*.txt`(타일맵)
- `src/main.js` — 고정 시간 간격 게임 루프, 메뉴·방 진행, 카메라. 타격 판정 `combat.js`, 이펙트 `effects.js`, 화면 글자 `hud.js`
- `src/player.js` — 캐릭터 본체. 무기 `playerWeapon.js`, 대시 `playerDash.js`, 내리꽂기 `playerSlam.js`, 분동 갈래 `spinCharge.js`
- `src/chain.js`, `src/flailStorm.js` — 던지는 사슬(대시 사슬·당기기)과 철퇴 폭풍. 결박 갈래 `bindChains.js`·`bindPull.js`
- `src/enemy.js`, `src/chargerAI.js`, `src/status.js` — 적, 돌격형 AI, 상태이상(화상·둔화·빙결 등)
- `src/tags.js`, `src/tagEffects.js` — 태그 공명 효과. 투사체 `projectiles.js`
- `src/skills.js`, `src/skillUI.js` — 스킬 트리 로직과 화면. `src/world.js`, `src/physics.js` — 타일맵과 충돌, `src/input.js` — 입력
- `tests/regress.cjs` — 결정적 회귀 재생, 테스트 방법은 `docs/TESTING.md`

프로젝트 규칙과 컨셉은 [CLAUDE.md](CLAUDE.md) 참고.
