## 플레이
**https://frong1110.github.io/newgame/**

`main` 브랜치에 push될 때마다 GitHub Actions가 자동으로 빌드해서 위 주소에 배포합니다.

## GitHub에서 직접 해야 하는 설정 (최초 1회)
1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
2. 작업 브랜치를 `main` 에 머지합니다. 배포는 `main` 에 push될 때만 실행됩니다.
3. **Actions** 탭에서 `Deploy to GitHub Pages` 워크플로가 초록색으로 끝났는지 확인하고 위 주소에 접속합니다.
   - 첫 배포 전에 1번을 하지 않았다면 실패하므로, 설정 후 Actions 탭에서 **Re-run jobs** 를 누릅니다.
   - 워크플로 화면의 **Run workflow** 버튼으로 수동 배포도 할 수 있습니다.
4. 저장소가 **비공개(private)** 라면 무료 플랜에서는 Pages를 쓸 수 없습니다. 공개로 바꾸거나 유료 플랜이 필요합니다.

## 모바일
휴대폰·태블릿에서 열면 화면 버튼이 자동으로 나옵니다. **가로 화면**으로 플레이합니다. (PC 에서 버튼을 보려면 주소 끝에 `?touch=1`)

|---|---|

| 점프 | Space |
| 공격 | X (꾹 누르면 연속) |

| 대시 | Shift |

## 프로토타입 v0.1 — 이동 / 점프 / 2단 점프

### 조작
| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| Space | 점프 (공중에서 한 번 더 누르면 2단 점프, 짧게 누르면 낮게 점프) |
| X | 사슬 휘두르기. 박자 맞춰 연타하거나 꾹 누르면 3단 콤보 (채찍 → 되감아 치기 → 내려치기). 사슬 **끝부분(분동)** 으로 맞히면 추가 피해 |
| C | 특수: 사슬 당기기. 맞은 적을 앞으로 끌어와 잠깐 경직시킴 (↑↓ 로 위아래 조준) |
| Shift | 대시. 공중에서도 1번 가능, 대시 중에는 무적이라 적을 통과해 피할 수 있음 |
| K | 스킬 트리 (게임 일시정지). 테스트용으로 스킬을 클릭하거나 ↑↓ + Enter 로 배우기/해제, Q 로 주 무기 바꾸기(사슬 ↔ 검) |
| R | 처음부터 다시 (스킬·방 초기화) |

### 스킬
지금은 테스트용으로 **K 스킬 트리 화면에서 직접** 스킬을 배우거나 해제합니다. (방을 클리어하면 후보 중 하나를 고르는 창은 `src/data/skills.json` 의 `pickOnRoomClear` 를 `true` 로 바꾸면 다시 켜집니다.) 트리는 두 개입니다.

**사슬 (무기) 트리** — 결박·투척·분동 세 갈래, 갈래마다 3단계 (점선 칸은 설계만 있는 '준비 중')
- 결박 (완성)
  - **감기**: 끝부분 적중 시 적을 캐릭터와 사슬로 이어 1초 속박 (너무 멀어지면 끊어짐)
  - **연결**: 묶인 적끼리 사슬로 이어지고, 한 적이 받는 피해의 30%를 다른 묶인 적도 받음
  - **사슬 감옥**: 묶인 적이 죽으면 주변 200px 안의 적 최대 3마리에게 사슬이 옮겨 붙어 속박
- 투척 (완성)
  - **회전 투척**: 당긴 적을 휘둘러 앞으로 던짐(던진 적·맞은 적 모두 피해). C 를 누를 때나 당기는 동안 **↑** 를 누르면 대신 **위로 띄움**
  - **내리찍기**: 공중 상태(하늘색 테두리 + ▲)인 적이 근처에 있으면 C 가 그 적을 자동으로 감아 바닥에 꽂고 충격파. 대기시간을 무시해서 ↑+C 로 띄운 직후 C 로 바로 이어짐
  - **철퇴 폭풍**: 당긴 적을 사슬 끝에 매달고 360도 돌려 휘말린 적 모두 피해, 다 돌면 위로 띄움 → 바로 C 로 내리찍기
- 분동: **사슬 늘이기**(사거리 +30%, 끝부분 확대) → **분동 강타**(끝부분 피해 +50%, 짧은 기절) → 채찍 폭풍

**대시 (이동) 트리**
1. **대각선 대시** — Shift 를 ↑↓(+←→) 와 함께 누르면 위·아래·대각선으로 대시
2. **사슬** — 대시 대신 사슬을 던짐. 지형·적에 걸리면 잠깐 멈칫한 뒤 바로 그곳으로 날아가고, 적이면 붙으며 피해
3. **내리꽂기** — 사슬로 이동한 직후(머리 위 ▼ 표시) 공격하면 분동을 머리 위로 크게 휘둘러 앞쪽 땅에 내리꽂고, 몸 앞부터 분동이 떨어진 곳까지의 적에게 큰 피해. 맞은 적은 사슬 끝부분 거리로 밀려나서 바로 X 로 끝부분 적중을 이어 칠 수 있음

### 구조
- `src/data/` — 속도, 중력, 점프력 등 모든 수치(`player.json`, `enemies.json`, `game.json`), 스킬(`skills.json`)와 레벨(`levels/*.txt`). 튜닝은 여기서
- `src/input.js` — 키보드 입력 (누름/뗌을 프레임 단위로 구분)
- `src/world.js` — 타일맵 충돌·렌더링
- `src/player.js` — 캐릭터 이동, 점프, 공격, 피격
- `src/enemy.js` — 테스트용 적 (순찰, 피격, 리스폰)
- `src/physics.js` — 타일 충돌, 겹침 판정
- `src/chain.js` — 던지는 사슬 (대시 사슬 스킬, 당기기)
- `src/skills.js`, `src/skillUI.js` — 스킬 트리 로직과 선택·트리 화면
- `src/main.js` — 고정 시간 간격 게임 루프, 카메라
