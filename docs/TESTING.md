# 테스트 가이드

**평소에는 읽지 않는다.** 필요할 때만 연다 (`CLAUDE.md` 의 '테스트 규칙' 참고).
- 작은 변경 → 아래 '기능별 확인 항목' 에서 바뀐 부분만 찾아서 확인
- 구조를 바꾸는 작업 → '회귀 재생' 을 돌린다

## 1. 어떤 변경에 무엇을 하나

| 변경 | 하는 것 | 생략하는 것 |
|---|---|---|
| 수치 조정, 스킬 하나 추가·수정, 버그 수정, 연출, 문서 | 바뀐 기능만 아래 항목으로 확인 + `npm run build` | 회귀 재생, graphify 재생성 |
| 파일 분리·합치기, 공용 모듈(`physics.js`, `input.js`, `enemy.js`, `chain.js`) 수정, 프레임 진행 순서 변경 | 회귀 재생 (바꾸기 **전·후**) + `npm run build` | graphify (요청 때만) |
| 큰 구조 변경이 끝난 뒤 | 위 + 필요하면 graphify | |

graphify 결과물(`graphify-out/`)은 저장소에 올리지 않는다(.gitignore). 사용자가 요청할 때 로컬에서만 만든다.

## 2. 준비

```bash
npm run dev            # http://localhost:5173
```
- 브라우저 자동화는 Playwright 를 쓴다 (클라우드 환경에는 설치돼 있음).
- 개발 서버에서만 `window.__game` 이 있다 (`player`, `enemies`, `world`, `skillTree`, `Input`, `projectiles`, `bindPull`, `mode`, `room`, `hitstop`).
  - `__game.pause()` 로 실시간 루프를 멈추고 `__game.tick(n)` 으로 고정 간격 n 프레임을 진행하면 같은 입력에 항상 같은 결과가 나온다.
  - `__game.Input.pressVirtual('KeyX')` / `releaseVirtual('KeyX')` 로 키를 누른다. 누른 키는 다음 `tick` 에서 처리된다.
- 스킬은 코드로 바로 배울 수 있다: `skillTree.reset(); skillTree.learnWithRequirements('cw_slam'); player.stats = skillTree.stats`

### 함정
- **분동·결박 새 동작은 회귀 기준 기록이 바뀐다** (0.3.7 에서 의도적으로 바뀜: 꾹 누르기 = 차지, 연결 삭제). 기록은 새로 만든다.
- **히트스톱**: 맞는 순간 `tick` 이 입력을 처리하지 않고 시간만 줄인다. 키를 누른 직후 바로 결과를 보지 말고 몇 프레임 더 진행한다.
- **적 체력은 소수**일 수 있다 (사슬 감옥 폭발 1.5배수, 회전 차지 방출 배율). 비교할 때 반올림하지 않는다.
- **레벨 파일(`levels/level1.txt`)이 바뀌면 좌표가 달라진다.** 테스트 위치(플레이어 x≈1500 의 넓은 땅, 낭떠러지 x 1280~1407 등)를 다시 확인하고, **회귀 기준 기록도 새 레벨에서 다시 만든다.**
- 적이 걸어 다니면 위치가 흔들린다. 적을 고정하려면 `stunTimer = 99` 로 둔다.

## 3. 회귀 재생

같은 입력을 고정 프레임으로 재생해 상태 기록을 남기고, 바꾸기 전과 후를 비교한다. 일부러 바꾼 장면만 달라야 한다.

```bash
# 1) 바꾸기 전 (변경을 stash 하거나 main 에서)
npm run dev &                                   # 개발 서버
node tests/regress.cjs /tmp/base.json

# 2) 변경 후
node tests/regress.cjs /tmp/after.json

# 3) 비교
node tests/compare.cjs /tmp/base.json /tmp/after.json
```
- 기록 713개(장면 label 별): 이동·점프·콤보·대시 / 회전 차지(탭·홀드) / 당기기·투척·띄우기·내리찍기·철퇴 폭풍 / 감기·팽팽한 줄·감옥 / 사슬 이동(낭떠러지)·내리꽂기 / 검 / 방 클리어.
- 같은 코드를 두 번 돌렸을 때 기록이 똑같아야 정상이다 (결정적). 다르면 테스트 쪽 문제부터 의심한다.
- **새 기능을 넣으면** `tests/regress.cjs` 에 그 기능 장면을 추가하고, 기준 기록을 다시 만든다.
- 기준 기록은 `main` 의 레벨·데이터 기준이어야 한다. `main` 이 바뀌었으면 기준을 다시 만든다.

## 4. 기능별 확인 항목

기대값은 기본 데이터 기준이다. 수치를 바꿨으면 기대값도 바뀐다.

### 이동·점프·대시
- [ ] 좌우 이동, 점프, 2단 점프(공중에서 한 번 더), 점프 키를 일찍 떼면 낮게 점프
- [ ] Shift 대시: 땅·공중 1회, 대시 중 무적(적을 통과해도 피격 0), 대기시간 0.45초 안에는 다시 안 나감
- [ ] 키보드와 화면 버튼이 같은 키를 눌러도 따로 추적됨 (한쪽을 떼도 다른 쪽은 누른 상태)

### 사슬 휘두르기 (X)
- [ ] 3타 콤보(채찍 → 되감아 치기 → 내려치기), 꾹 누르면 반복
- [ ] 적과의 거리별 1타(기본): 30px 몸통(피해 1) / 85px 끝부분(피해 2) / 125px 빗나감
- [ ] 끝부분 적중 시 번쩍임·불꽃·효과음 재생 함수 1회 (`playSfx` 호출 수)
- [ ] 끝부분 피해 = (몸통 + (끝부분 − 몸통) × `tipBonusMultiplier`) × `tipDamageMultiplier`

### 분동 갈래
- [ ] **회전 차지**: X 탭(0.15초 안에 떼기) = 일반 휘두르기(길이 보정 없음). 꾹 누르면 `charging`(이동 40%, 머리 위 궤도·차지 막대), 놓으면 3타(내려치기) 방출: 차지량만큼 속도 +50%·피해 +50% 까지, 앞의 가장 가까운 적에 사슬 길이 보정(`swingLengthScale` ≠ 1). 방출 거리별 끝부분 판정 — 10·25px 몸통 / 45~145px 끝부분 / 170px 빗나감
- [ ] 끝부분 피해: 기본 1·2타 2, 3타 3 / 회전 차지 1.5·1.5·2 (방출 차지 배율 별도). 분동 그림 1.6배, 끝부분 판정 길이·두께 1.5배
- [ ] 회전 차지 중 맞거나 대시하면 차지 취소
- [ ] **쳐내기**(P 키 = 투사체 테스트 발사): 돌리는 중 반경(70px) 안에 들어온 투사체는 없어지고 분동에 저장(`storedShots`, 최대 5, 가득 차면 바로 반사). 돌리지 않을 때는 맞아서 피격
- [ ] **쳐내기 축적**: 방출하면 저장한 수만큼 부채꼴(70°)로 반사(1개는 정면), 반사 투사체가 적에게 닿으면 피해 2
- [ ] **채찍 폭풍**: 쳐내기 또는 돌리는 분동(반경 안)이 적에게 닿을 때(적마다 0.5초 간격, 피해 1) 회전 스택 +1(최대 5, 5초 유지). 스택당 차지 속도 +20%·반경 +12%. 최대 스택으로 방출하면 `swingStorm` 원형 타격 + 저장한 투사체 전방위 반사, 스택 0으로 소모
- [ ] 태그 연결: 반사 투사체 적중 `reflectHit`, 최대 스택 방출 타격 `releaseHit` 가 `tags.js` `emitTag` 로 나감 (`onTag` 로 구독해 확인)

### 결박 갈래
- [ ] **감기**: 끝부분 적중 → 속박 1초, 넉백 없이 제자리, 캐릭터와 사슬로 연결, 260px 넘게 멀어지면 끊어짐. 동시에 3명까지(4번째를 묶으면 남은 시간이 가장 짧은 적이 풀림)
- [ ] **팽팽한 줄**: 묶인 적 둘 사이 선(굵기 8px)에 닿은 묶이지 않은 적 → 피해 1(0.5초마다) + 속박 1초(묶인 수가 3 미만일 때). 피해 공유는 없음
- [ ] 팽팽한 줄 C(묶인 적 2명 이상): 0.3초 동안 무게중심으로 모여 충돌 → 각 피해 2·기절 1초, 사슬 풀림. 1명이면 일반 당기기. 대기시간 0.8초
- [ ] **사슬 감옥**: 묶인 적이 죽으면 200px 안의 가까운 적 최대 3마리에게 사슬이 옮겨 붙음(120·180px 는 속박, 240·340px 는 아님), 연쇄 가능
- [ ] 사슬 감옥 C: 한 점으로 모인 뒤 0.3초 조임(줄어드는 원) → 폭발. 피해 = 2 + 1.5 × (묶은 수 − 1), 반경 = 70 + 15 × 묶은 수, 반경 안 모든 적이 맞음. 폭발로 죽은 묶인 적은 전이 발동

### 투척 갈래 (C 당기기)
- [ ] 당기기: 앞의 적을 끌어와 0.7초 경직, 피해 0, 지형에는 걸리지 않음, ↑↓ 조준(회전 투척이 없을 때)
- [ ] **회전 투척**: 당긴 적을 앞으로 던짐(던진 적·맞은 적 모두 피해 1), ↑ 를 누른 채 당기면 띄움(약 130px, 체류 0.7초)
- [ ] 던져지거나 띄워진 적에 공중 표시(하늘색 테두리 + ▲), 땅에 닿으면 사라짐
- [ ] **내리찍기**: 공중 상태 적이 340px 안이면 C 가 대기시간을 무시하고 그 적을 감아 바닥에 꽂음(꽂힌 적 −3, 근처 적 −2), 스킬이 없으면 발동 안 함
- [ ] **철퇴 폭풍**: C → 회전(한 바퀴 0.5초, 최대 2초, 바퀴마다 옆의 적 −2) → C 로 던짐(앞으로 약 237px, 0.74초 비행) → C 로 내리찍기. 회전 중 적이 땅에 파묻히지 않음(발 y ≤ 땅). ↑ 를 누른 채 당기면 돌리지 않고 띄움

### 대시 트리
- [ ] **대각선 대시**: 스킬이 없으면 ↑+→ 도 수평, 있으면 오른쪽 위 / ↑ 만 누르면 수직
- [ ] **사슬**: 지형·적에 걸리면 한 번에 날아감(벽 앞 x=224 에서 멈춤, 적에게는 붙으며 피해). 아무것도 없으면 되감기
- [ ] 낭떠러지 건너편 같은 높이 적에게 끊기지 않고 도착 (예전엔 x≈552 에서 끊겨 떨어짐), 발판 위 적도 도착
- [ ] **내리꽂기**: 사슬 이동 직후 0.8초 안에 X(이동 중 미리 눌러도 됨) → 분동을 머리 위로 휘둘러 앞쪽 땅에 꽂음. 가능할 때 머리 위 ▼. 0.8초 뒤에는 일반 공격
- [ ] 내리꽂기 범위: 몸 뒤 약간 ~ 분동 너머 16px 만 맞음 (몸에 붙은 적 O, 분동 너머 +150px 는 X), 맞은 적은 1타 끝부분 거리로 밀림
