# 테스트 가이드

**평소에는 읽지 않는다.** 필요할 때만 연다 (`CLAUDE.md` 의 '테스트 규칙' 참고).
- 작은 변경 → 아래 '기능별 확인 항목' 에서 바뀐 부분만 찾아서 확인
- 구조를 바꾸는 작업 → '회귀 재생' 을 돌린다

## 1. 어떤 변경에 무엇을 하나

| 변경 | 하는 것 | 생략하는 것 |
|---|---|---|
| 수치 조정, 스킬 하나 추가·수정, 버그 수정, 연출, 문서 | 바뀐 기능만 아래 항목으로 확인 + `npm run build` | 회귀 재생, graphify 재생성 |
| 파일 분리·합치기, 공용 모듈(`physics.js`, `input.js`, `enemy.js`, `chain.js`) 수정, 프레임 진행 순서 변경 | 회귀 재생 (바꾸기 **전·후**) + `npm run build` | graphify (요청 때만) |
| 큰 구조 변경이 끝난 뒤 | 위 + 필요하면 graphify | |

graphify 결과물(`graphify-out/`)은 저장소에 올리지 않는다(.gitignore). 사용자가 요청할 때 로컬에서만 만든다.

## 2. 준비

```bash
npm run dev            # http://localhost:5173
```
- 브라우저 자동화는 Playwright 를 쓴다 (클라우드 환경에는 설치돼 있음).
- 개발 서버에서만 `window.__game` 이 있다 (`player`, `enemies`, `world`, `skillTree`, `Input`, `projectiles`, `bindPull`, `tagEffects`, `mode`, `room`, `hitstop`).
  - `__game.pause()` 로 실시간 루프를 멈추고 `__game.tick(n)` 으로 고정 간격 n 프레임을 진행하면 같은 입력에 항상 같은 결과가 나온다.
  - `__game.Input.pressVirtual('KeyX')` / `releaseVirtual('KeyX')` 로 키를 누른다. 누른 키는 다음 `tick` 에서 처리된다.
- 스킬은 코드로 바로 배울 수 있다: `skillTree.reset(); skillTree.learnWithRequirements('cw_slam'); player.stats = skillTree.stats`

### 함정
- **분동·결박 새 동작은 회귀 기준 기록이 바뀐다** (0.3.7 에서 의도적으로 바뀜: 꾹 누르기 = 차지, 연결 삭제). 기록은 새로 만든다.
- **히트스톱**: 맞는 순간 `tick` 이 입력을 처리하지 않고 시간만 줄인다. 키를 누른 직후 바로 결과를 보지 말고 몇 프레임 더 진행한다.
- **적 체력은 소수**일 수 있다 (사슬 감옥 폭발 1.5배수, 회전 차지 방출 배율, 태그 %피해). 비교할 때 반올림하지 않는다.
- **기본 맵은 `levels/bind.txt`(결박 시험장), 회귀 재생·좌표 기준은 `levels/level1.txt`** — 개발 서버 주소에 `?level=level1` 을 붙인다 (`tests/regress.cjs` 는 자동). 결박 시험장 구역: D 타일 x 1~30(돌격형 4마리, **맨 왼쪽**), A 33~55(적 4마리, 간격 64px, 플레이어 시작 x=34), B 57~77(적 3마리, 간격 224px), C 79~101(적 5마리 + 발판 위 1마리). 구역 경계는 2칸 기둥(x 31, 56, 78). (이전 좌표에서 D 를 왼쪽에 붙이며 A~C 가 +32 이동)
- **레벨 파일이 바뀌면 좌표가 달라진다.** 테스트 위치(플레이어 x≈1500 의 넓은 땅, 낭떠러지 x 1280~1407 등)를 다시 확인하고, **회귀 기준 기록도 새 레벨에서 다시 만든다.**
- 적이 걸어 다니면 위치가 흔들린다. 적을 고정하려면 `stunTimer = 99` 로 둔다.

## 3. 회귀 재생

같은 입력을 고정 프레임으로 재생해 상태 기록을 남기고, 바꾸기 전과 후를 비교한다. 일부러 바꾼 장면만 달라야 한다.

```bash
# 1) 바꾸기 전 (변경을 stash 하거나 main 에서)
npm run dev &                                   # 개발 서버
node tests/regress.cjs /tmp/base.json

# 2) 변경 후
node tests/regress.cjs /tmp/after.json

# 3) 비교
node tests/compare.cjs /tmp/base.json /tmp/after.json
```
- 기록 713개(장면 label 별): 이동·점프·콤보·대시 / 회전 차지(탭·홀드) / 당기기·투척·띄우기·내리찍기·철퇴 폭풍 / 감기·팽팽한 줄·감옥 / 사슬 이동(낭떠러지)·내리꽂기 / 검 / 방 클리어.
- 같은 코드를 두 번 돌렸을 때 기록이 똑같아야 정상이다 (결정적). 다르면 테스트 쪽 문제부터 의심한다.
- **새 기능을 넣으면** `tests/regress.cjs` 에 그 기능 장면을 추가하고, 기준 기록을 다시 만든다.
- 기준 기록은 `main` 의 레벨·데이터 기준이어야 한다. `main` 이 바뀌었으면 기준을 다시 만든다.

## 4. 기능별 확인 항목

기대값은 기본 데이터 기준이다. 수치를 바꿨으면 기대값도 바뀐다.

### 이동·점프·대시
- [ ] 좌우 이동, 점프, 2단 점프(공중에서 한 번 더), 점프 키를 일찍 떼면 낮게 점프
- [ ] Shift 대시: 땅·공중 1회, 대시 중 무적(적을 통과해도 피격 0), 대기시간 0.45초 안에는 다시 안 나감
- [ ] 키보드와 화면 버튼이 같은 키를 눌러도 따로 추적됨 (한쪽을 떼도 다른 쪽은 누른 상태)

### 사슬 휘두르기 (X)
- [ ] 3타 콤보(채찍 → 되감아 치기 → 내려치기), 꾹 누르면 반복
- [ ] 적과의 거리별 1타(기본, 적 왼쪽 끝까지 거리): 60~75px 몸통(피해 10) / 80~125px **끝부분(피해 20, 구간 약 50px — 전 40px 에서 ×1.3)** / 130px 이상 빗나감
- [ ] 끝부분 적중 시 번쩍임·불꽃·효과음 재생 함수 1회 (`playSfx` 호출 수)
- [ ] 끝부분 피해 = 몸통 + (끝부분 − 몸통) × `tipBonusMultiplier`(1), 방출 휘두르기는 × 차지 배율

### 스킬 피해 = 사슬 데미지의 배수
- [ ] **사슬 데미지 단위** = 사슬 1타 몸통 피해(`chainWeapon.combo[0].damage`, 지금 10, `player.chainDamage`). 스킬 피해 수치(`player.json`)는 이 값의 **배수**로 적고 쓸 때 곱함 → 사슬 데미지를 바꾸면 스킬 피해도 같은 비율로 변함. 확인: `pl.stats.chainWeapon.combo[0].damage = 20` 이면 아래 값이 전부 2배
- [ ] 단위 10 일 때: 투척 내리찍기 대상 30(+띄우기 10 → 합 40)·주변 20 / 대시 내리꽂기 40 / 회전 투척 10(던진 적 자체 10) / 철퇴 폭풍 붙잡기 10·앞 비행 20·벽 폭발 30(주변 20)·↓ 30(주변 20) / 팽팽한 줄 선 10·충돌 20 / 사슬 감옥 폭발 20 + 15×(묶은 수−1) / 쳐내기 반사 20·회전 분동 접촉 10 / 대시 사슬 붙을 때 10 / 번개 폭발 30·얼음 파편 15(`tags.json` 배수 3·1.5)
- [ ] 비례하지 않는 것: 끝부분 피해(콤보 데이터 `damage`·`tipDamage` 자체가 사슬 데미지), 화상(최대 체력 %), 처형(체력 %), 번개 연쇄(맞은 피해 × 0.5)

### 분동 갈래
- [ ] **회전 차지**: X 탭(0.15초 안에 떼기) = 일반 휘두르기(길이 보정 없음). 꾹 누르면 `charging`(이동 40%, 머리 위 궤도·차지 막대), 놓으면 3타(내려치기) 방출: 차지량만큼 속도 +50%·피해 +50% 까지, 앞의 가장 가까운 적에 사슬 길이 보정(`swingLengthScale` ≠ 1). 방출 거리별 끝부분 판정(방출 사슬 길이 +40% → 3타 125 → 175px, 자동 보정 최대 ×1.9 → 사슬 최대 약 333px) — 40~330px 끝부분(적이 없으면 보정 없이 175px) / 340px 이상 빗나감. **탭 1타는 스킬이 있어도 사슬 110px·끝부분 구간 80~125px 그대로**, 방출 후 이어지는 탭도 110px
- [ ] 끝부분 피해: 1·2타 20, 3타 30 (몸통 10). **회전 차지도 추가 피해 감소 없음**(`tipBonusMultiplier` 1) — 방출은 여기에 차지 배율(최대 +50%)만 곱함. **회전 차지 방출 사슬 길이 +40%**: `chainWeapon.chargeLengthMul` 1 → 1.4 — 방출 휘두르기에만 적용(기본 공격·탭의 `lengthMultiplier` 는 1 그대로). 끝부분 판정 길이·두께와 분동 그림은 모든 사슬 휘두르기에서 기본 1.3배(`tipHitMultiplier`·`weightModelScale`, 전 1배), 끝부분 인정 최소 뻗음 `minTipExtension` 0.7 → 0.61
- [ ] 회전 차지 중 맞거나 대시·기절하면 차징 취소 + **차지량·저장·회전 스택 모두 0** (다시 시전하면 처음부터). 끊김 없이 방출한 경우만 스택이 5초 유지
- [ ] **쳐내기**(P 키 = 투사체 테스트 발사): 돌리는 중 반경(70px) 안에 들어온 투사체는 없어지고 분동에 저장(`storedShots`, 최대 5, 가득 차면 바로 반사). 돌리지 않을 때는 맞아서 피격
- [ ] **쳐내기 축적**: 방출하면 저장한 수만큼 부채꼴(전방 75°)로 반사(1개는 정면), 반사 투사체가 적에게 닿으면 피해 ×2(= 20)
- [ ] **채찍 폭풍 범위**(최대 스택 방출, 사슬 앞, 기존의 +50%): 전방 255px·상하 ±105px·뒤 30px 의 반타원. 중심 기준 전방 250px·위아래 100px·뒤 10px 는 맞음, 전방 280px·위아래 125px·뒤 45px 는 안 맞음. 저장한 투사체는 전방 150° 부채꼴
- [ ] **채찍 폭풍**: 쳐내기 또는 돌리는 분동(반경 안)이 적에게 닿을 때(적마다 0.5초 간격, 피해 ×1 = 10) 회전 스택 +1(최대 5, 5초 유지). 스택당 차지 속도 +20%·반경 +12%. 최대 스택으로 방출하면 `swingStorm` 원형 타격 + 저장한 투사체 전방위 반사, 스택 0으로 소모
- [ ] 태그 연결: 반사 투사체 적중 `reflectHit`, 최대 스택 방출 타격 `releaseHit` 가 `tags.js` `emitTag` 로 나감 (`onTag` 로 구독해 확인)

### 결박 갈래
- [ ] **감기**: 끝부분 적중 → 속박 1초(넉백 없이 제자리, 흰 막대), 사슬은 3초 유지(보라 가는 막대: 속박이 풀려 걸어 다녀도 사슬은 남고 팽팽한 줄·C·전이 대상), 260px 넘게 멀어지면 끊어짐. 동시에 3명까지(4번째를 묶으면 남은 시간이 가장 짧은 적이 풀림)
- [ ] **속박 내부 쿨타임**(`enemies.json` `bindCooldown` 1.5초): 속박(제자리 고정)이 끝나거나 도중에 풀린 직후 1.5초 동안은 새로 묶이지 않음(`bindTimer` 0 유지, 적이 걸어 다님). **연결은 해당 없음** — 쿨타임 중에도 맞으면 사슬 연결 시간이 3초로 리셋됨(`chainTimer`). 쿨타임이 끝나면 다시 속박. **속박 중 다시 맞아도 속박 시간은 리셋되지 않음**(남은 시간 그대로, 연결만 3초로 리셋 — 예: 속박 0.5초 남은 상태에서 재적중 → 속박 0.5초·연결 3초). 연결 3초가 만료돼 풀린 경우는 쿨타임 없음(속박은 이미 끝남)
- [ ] **팽팽한 줄**: 묶인 적 둘 사이 선(굵기 8px)에 닿은 묶이지 않은 적 → 피해 ×1 = 10(0.5초마다) + 속박 1초(묶인 수가 3 미만일 때). 피해 공유는 없음
- [ ] 팽팽한 줄 C(묶인 적 2명 이상): 0.3초 동안 무게중심으로 모여 충돌 → 각 피해 ×2 = 20·기절 1초, 사슬 풀림. 1명이면 일반 당기기. 대기시간 0.8초
- [ ] **사슬 감옥**: 묶인 적이 죽으면 200px 안의 가까운 적 최대 3마리에게 사슬이 옮겨 붙음(120·180px 는 속박, 240·340px 는 아님), 연쇄 가능
- [ ] 사슬 감옥 C: 한 점으로 모인 뒤 0.3초 조임(줄어드는 원) → 폭발. 피해 = (2 + 1.5 × (묶은 수 − 1)) × 사슬 데미지(3마리면 50), 반경 = 70 + 15 × 묶은 수, 반경 안 모든 적이 맞음. 폭발로 죽은 묶인 적은 전이 발동

## 문·한 방향 발판 (`?level=stage1`)
- 발판(`=`): 아래에서 점프하면 통과하고 위에 착지(발바닥 y = 발판 윗면). 문(`D`): 적이 남아 있으면 닫힘(회색), 전멸하면 하늘색으로 열리고 닿으면 시작 위치로 이동·적 재배치.

## 근접형·방 조각 (`?level=stage1`)
- 근접형: 가까이 가면 idle → windup(0.35) → active(0.12) → recover(0.6) 순환, 맞으면 플레이어 피격(무적 시작). 방 조각 4개: 적 전멸 후 문에 닿으면 cells → pit → labor → gallery → cells 로 이동(적 종류: 각 방 설명은 CLAUDE.md).

## 시작 화면 (주소에 ?level= 없이)
- 처음엔 mode 'menu'(게임 시작 → Enter → 스테이지 선택 → Enter) → mode 'intro' 동안 플레이어가 입력해도 움직이지 않고 적도 멈춤, `stageIntroTime` 뒤 'play'. 플레이 중 Esc → 다시 'menu'. `?level=...` 이면 처음부터 'play'.

## 발판 내려가기 (`?level=gallery`)
- 발판 위에서 ArrowDown 을 누른 채 Space → 발판 아래로 통과해 아래 바닥/발판에 착지(`dropTop` 은 통과 뒤 null). 땅 위에서 ↓+Space 는 그냥 점프, ↓ 없이 Space 는 점프. 모바일은 `?touch=1` 로 같은 키 코드가 들어가는지 확인.
